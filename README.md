# Synchronous-FIFO-SystemVerilog-Verification
Synchronous FIFO designed in Verilog and verified using SystemVerilog/UVM. Testbench built with Driver, Monitor, Scoreboard, and Sequencer to check read/write behavior, full/empty flags, and boundary conditions. Verified functional correctness by comparing expected vs actual data through the scoreboard, with waveform debug done in EDA Playground.
